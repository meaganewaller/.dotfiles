# Ruby User Guides & Tutorials

Guides are for humans. They should answer:
- how to start
- what’s safe
- what breaks
- how to debug
- how to extend

## Required Guide Sections (Recommended)

### Getting Started
- prerequisites
- install
- configure (env vars, credentials)
- run locally
- run tests
- common setup failures

### Concepts
- core domain objects
- “mental model” section
- invariants and rules

### Usage
- common workflows
- real examples
- anti-patterns

### Troubleshooting
- common errors and fixes
- logging locations
- how to reproduce failures

### FAQ
- design tradeoffs
- “why does it work this way?”

## Example Style Rules

- Use real values and real shapes (not toy payloads)
- Keep steps copy/paste friendly
- Include expected output for key commands
- Prefer one good diagram over five paragraphs

## Rails App Guides

Include:
- how to run server
- background jobs
- local dependencies (redis, postgres)
- seeds and fixtures
- auth setup
- API testing approach

## Gem Guides

Include:
- installation
- configuration
- public API overview
- extension points
- compatibility matrix (Ruby/Rails versions)
