# [Claude Code](https://code.claude.com/docs/en/overview) Config

This repository houses all of my Claude Code configuration that will be resolved by profile (currently I have `work` and `profile`) with the `common` configs and symlinked into place at `$HOME/.claude`. The install script is available at [`./install.sh`](./install.sh)

To install, run `mise run claude` (defaults to `work` profile), `mise run claude --profile=personal` for personal profile.
